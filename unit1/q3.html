Q3. Types of Computer Forensics

Introduction

Computer forensics means collecting and checking digital evidence from computers, mobile phones, networks, and other digital devices.

It helps investigators find out how a cyber crime happened and who was involved.

Types of Computer Forensics

1. Network Forensics

Network forensics means checking the data that travels through a computer network.

Investigators check network activity to find hacking, unknown connections, and people accessing the network without permission.

They use tools like Intrusion Detection Systems (IDS) to detect suspicious activity and other tools to examine network traffic, website visits, and file transfers.

Example: Investigators check network records to find how a hacker entered a company’s network.

2. Email Forensics

Email forensics means checking emails to find evidence of cyber crimes.

Investigators examine sent, received, and deleted emails. They also check email addresses, IP addresses, dates, times, and attached files.

It helps investigate fake emails, threats, phishing, and email fraud.

Example: Investigators check a fake bank email to find details about the sender.

3. Malware Forensics

Malware forensics means checking harmful software used in cyber crimes.

Investigators examine viruses, worms, Trojans, spyware, and backdoors to understand how they work and what damage they cause.

It helps find how the malware entered the computer and what information or files it affected.

Example: Investigators examine a virus to find how it entered a computer and stole information.

4. Memory Forensics

Memory forensics means checking information stored in a computer’s memory, mainly RAM.

RAM stores temporary information about programs and activities running on a computer.

Investigators check RAM to find hidden viruses, suspicious programs, and other evidence.

Example: Investigators check a computer’s RAM to find a harmful program running secretly.

5. Mobile Phone Forensics

Mobile phone forensics means collecting and checking information from mobile phones and tablets.

Investigators examine call records, messages, photos, videos, browsing history, app data, and location details.

This helps them find evidence related to cyber crimes.

Example: Investigators examine a suspect’s phone to find WhatsApp messages related to online fraud.

6. Database Forensics

Database forensics means checking information stored in a database to find evidence of cyber crimes.

Investigators examine stored records, changes made to data, user activities, and metadata (details about the data).

It helps find stolen information, deleted records, and changes made without permission.

Example: Investigators check a bank’s database to find who illegally changed transaction records.

7. Disk Forensics

Disk forensics means checking information stored on hard disks, SSDs, pen drives, and other storage devices.

Investigators search for existing, changed, hidden, and deleted files.

It helps recover important information and find what activities were performed on a computer.

Example: Investigators recover deleted files from a suspect’s hard disk during a cyber crime investigation.

Conclusion

Different types of computer forensics help investigators collect and check digital evidence from networks, emails, malware, memory, mobile phones, databases, and storage devices.

They help investigators understand cyber crimes and identify the people involved.
